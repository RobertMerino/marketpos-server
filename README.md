# 🍽️ MarketPOS Pro

Sistema profesional para restaurantes - Punto de Venta y Menú Digital QR.

## 🚀 Características

- 📱 Menú Digital QR para clientes
- 👨‍🍳 Pantalla de Cocina en tiempo real
- 📊 Dashboard de ventas
- 🪑 Gestión de mesas
- 🛎️ Pedidos online
- ⏱️ Temporizador de pedidos
- 🔴 Alertas de retraso

## 📦 Archivos

| Archivo | Descripción |
|---------|-------------|
| `index.html` | Panel principal (admin/mesero) |
| `cocina.html` | Pantalla de cocina |
| `mesero.html` | App para meseros (celular) |
| `menu-digital.html` | Menú QR para clientes |
| `app.js` | Lógica principal |
| `database.js` | Base de datos local |
| `estilos.css` | Estilos profesionales |

## ⚡ Instalación

1. Clonar el repositorio
2. Abrir `index.html` con Live Server
3. ¡Listo!

## 📱 Uso en celular

Abrir `mesero.html` desde el celular en la misma red WiFi.

## 🛠️ Tecnologías

- HTML5, CSS3, JavaScript (Vanilla)
- LocalStorage para persistencia
- Sin dependencias externas
